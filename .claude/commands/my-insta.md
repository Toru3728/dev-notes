# Instagram投稿文作成（Insta）

商品・サービスの「名前」と「特徴」を受け取り、親しみやすい口調のInstagram投稿文を作る。

## 入力
- 商品/サービス名と特徴（箇条書き・雑でOK）＝ $ARGUMENTS
- 名前か特徴が足りなければ「商品名と特徴を教えて」と一言だけ促す

## 出力フォーマット（この4構成を厳守・順番もこの通り）

```
<共感の一言>

<ベネフィット①>
<ベネフィット②>
<ベネフィット③>

<行動の呼びかけ>

<ハッシュタグ5個>
```

### 各パートの作り方
1. **共感の一言**（冒頭1〜2行）
   - 読み手の悩み・あるある・本音に寄り添うフックから入る
   - インスタは最初の1行で「続きを読むか」が決まる。問いかけ or 共感で引き込む
2. **ベネフィット3つ**
   - 特徴を**ベネフィット（それで何が嬉しいか）に翻訳**して書く（機能の羅列にしない）
   - 例: 「自動で記録」→「記録の手間が消えて、その分ゆっくりできる」
   - 1行ずつ。頭に絵文字を1つ添えると見やすい（✅ ✨ 😊 など）
3. **行動の呼びかけ（CTA）**
   - 1つに絞る（保存・コメント・プロフのリンク・DMで質問 など）
   - 「あとで見返せるように保存してね📌」のように具体的に
4. **ハッシュタグ5個**
   - ちょうど5個。商品ジャンル／ターゲット／お悩み系をミックス
   - 日本語中心。規模を散らす（大きめ2・中くらい2・ニッチ1 くらい）

## 口調・トーンのルール
- **親しみやすく**（フレンドリー、敬語すぎず・タメ口すぎず）。語りかけるように
- 絵文字は**ほどよく**（盛りすぎない）
- **誇大表現・ウソはNG**。特徴に無い効果を盛らない（とーるさん＝となりにAIのブランド＝安心・誠実に合わせる）
- 1投稿として読みやすい長さに（長文になりすぎない）

## オプション
- ユーザーが「フックだけ何個か」と言えば、共感の一言を2〜3パターン出す
- 改行・空行は上のフォーマット通り（インスタで読みやすい余白を保つ）

## 保存
- 完成した投稿文を `company/secretary/sns/YYYY-MM-DD_<商品名>.md` に保存
- 同日同名があれば連番（_2 など）
- 保存後「投稿文を保存したよ → パス」と簡潔に報告

## コミュニケーション
- フランクに。まず投稿文を表示してから保存報告する
