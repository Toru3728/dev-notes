# AIニュースリサーチ（AI News）

最新のAI情報をリサーチし、5つほどピックアップして簡単に説明する。
**必ず「となりにAI（介護DX）目線でのひとこと」を添える**のがこのコマンドの肝。

## 入力
- $ARGUMENTS にテーマ指定があればその領域で（例: 「介護」「画像生成」「エージェント」）
- 指定が無ければ「いま話題のAI全般」の最新情報を拾う

## やること
1. WebSearch で**直近（今月中心）**のAIニュースをリサーチする
   - 「AI 最新ニュース <今年><今月>」「latest AI news」等で検索
   - X（旧Twitter）は直接取得できないので、Xで話題の内容を拾うニュース系まとめも活用してよい
2. 重要・話題性の高いものを **5つ前後** に絞る
3. それぞれを**専門用語をかみ砕いて**簡単に説明する
4. 最後に「となりにAI目線」の示唆を必ず付ける

## 出力フォーマット

```
# AIニュース YYYY-MM-DD

## 🔥 注目AIニュース5選
1. **<見出し>** — <2〜3行で簡単に説明>
2. ...（5つ）

## 💡 となりにAI（介護DX）目線でのひとこと
- <介護現場・事業にどう効くか／研修・提案ネタになる視点を2〜3点>

**Sources:**
- [タイトル](URL)
（使った情報源をmarkdownリンクで列挙）
```

## 大事なルール
- **事実を創作しない**。検索で確認できたことだけ書く。不確かな点は「未確認」と添える
- 数字・固有名詞（評価額・モデル名・企業名）は検索結果に忠実に
- 「となりにAI目線」は、とーるさん＝AI×介護DXの伴走者にとっての**使いどころ・提案ネタ・研修ネタ**の角度で書く（安く・速く・ローカル＝個人情報安全、現場の事務作業の自動化、などに引きつけると刺さる）
- 親しみやすく・フランクに。専門用語は噛み砕く

## 保存（ローカル＋Googleドライブの両方に保存する）
1. ローカル: `company/secretary/news/AIニュース_YYYY-MM-DD.md`
2. Googleドライブ（同期フォルダ）: `H:\マイドライブ\となりにAI\AIニュース\AIニュース_YYYY-MM-DD.md`
   - これは Google Drive for Desktop の同期フォルダ（H: = toru.furukawa3728@gmail.com）。普通に書き込めば自動でGoogleドライブに上がる
   - 両方とも**同じ内容**を保存する
- 同日既存なら連番（_2 など）。ローカルとドライブで連番をそろえる
- 保存後「AIニュースを news（ローカル）と Googleドライブに保存したよ → 各パス」と簡潔に報告

## コミュニケーション
- フランクに。まず結果を表示してから保存報告する
