# Codexに別視点レビューを頼む（Codex Review）

提案書・note記事・SNS文などを、Codex CLIに読ませて別視点のレビューをもらう。

## 入力
- レビューしたいファイルのパス＝ $ARGUMENTS
- パスが無ければ「レビューしたいファイルを教えて」と一言だけ促す

## 手順
1. `which codex` でCodex CLIが入っているか確認。無ければ「Codex CLIが未インストールみたい。`npm i -g @openai/codex` で入れてログインしてね」と案内して止める
2. 次の形で非対話実行する（対象ファイルは編集させない）
   `codex exec --sandbox read-only "AGENTS.mdの方針に従って、<パス> をレビューして。ファイルは書き換えないこと。"`
3. 返ってきた指摘を、そのまま貼らずに整理して返す
   - 採用した方がいい指摘 / 参考程度 / 見送り、の3つに分ける
   - Claude側から見て同意できない指摘は、理由を一言添える
4. 直す場合は、とーるさんの了承を取ってから反映する

## 大事なルール
- Codexには**原文を書き換えさせない**（read-only）
- 顧客名・個人情報が含まれるファイルは、外部サービスに送ることになるので、実行前に一言確認する
- 簡潔に。口調はフランク、呼び方は「とーるさん」
