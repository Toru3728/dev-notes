# /my-shorts — 介護系YouTubeショート制作・リリース

介護×AIのショート動画を「ネタ→台本→制作→公開→分析」で回すコマンド。
口調はフランクに。仕組みの全体像は `company/shorts/workflow.md` を参照。

## 入力（$ARGUMENTS で分岐）
- `ネタ` … ネタ出しモード
- `台本 <テーマ>` … 台本作成モード（テーマは雑でOK）
- `公開` … 公開サポートモード
- `分析` … 振り返りモード
- 引数なし … 「どれやる？ ネタ出し／台本／公開／分析」と聞く（1回だけ）

## モード別の動き

### ネタ出し
1. `company/shorts/neta.md` を読み、未使用ネタから**今週の2本**を推薦（シリーズが偏らないように）
2. ネタが薄いときは vidiq の keyword_research（JP）で介護関連の検索需要を調べて新ネタを3〜5個提案し、neta.md に追記
3. `company/chousa/genba-faq.md` に新しい質問が増えていたらネタ化を提案

### 台本作成
テーマを受けて以下を一式生成し、`company/shorts/scripts/YYYY-MM-DD_<スラッグ>.md` に保存（同日同名は連番）。

**台本の型（30〜45秒・250〜350文字・話し言葉）**
```
【フック】0〜2秒。悩み・あるある・意外な事実。疑問形が強い
【本編】1メッセージ。ポイント最大3つ。専門用語はその場で翻訳
【CTA】1つだけ（例:「フォローで介護×AIのヒント、週2回」）
```

**ファイルに含めるもの**
1. 台本本文（Vrewにそのまま貼れるプレーンテキスト。1文＝1行で改行）
2. タイトル案3つ（40文字以内・「介護」or「AI」を前方に）
3. 概要欄（2〜3行の要約＋「※個別のケースはケアマネさん・地域包括にご相談を」）
4. ハッシュタグ: #Shorts ＋ 4個（介護系2・AI系1・悩み系1）※**概要欄の本文に入れるもの**（#付き・スペース区切り）
4b. **タグ欄用キーワード（別物・必ず付ける）**: YouTube Studioの「タグ」欄に入れる**#なし・カンマ区切り**のキーワード7個前後。コピペ用にコードブロックで出す。例:
   ```
   介護,介護離職,介護休業給付金,介護休業,仕事と介護の両立,家族介護,介護のお金
   ```
   ※ハッシュタグ（#付き・概要欄用）とタグ（#なし・タグ欄用）は別物。混同して#付きをタグ欄に入れると無効になるので、台本には両方を別々に用意する
5. Vrew用メモ（画面に出すテロップ強調ワード3つ＋**シーンごとのケアしば画像生成プロンプト**。`company/shorts/assets/care-shiba-video.md` の共通プロンプトをベースに、スタンプ既存8ポーズで足りるシーンは流用を指定）
6. **Vrew作業チェックリスト（必ず付ける）** — とーるさんは長尺制作を挟むと操作を忘れるので、台本ファイル単体で作業が完結するようにする。この動画固有の値を埋めた状態で出すこと（汎用の説明文にしない）:
   ```
   ## Vrew作業チェックリスト
   - [ ] 「テキストから動画を作成」→ 台本本文を貼る
   - [ ] AI音声「ミツキ」・速度ゆっくりめ
   - [ ] 画像を差し替え（上の表の通り。画像クリック →「交換」→「PCから読み込む」）
   - [ ] 強調テロップ: 「<この動画の強調ワード>」→「挿入」→「テキスト」→「書式」タブ → 文字色 HEX `D97706`（アンバー）
   - [ ] エンドカード: 最後のクリップを選択 →「挿入」→「空きクリップ」→ そこに画像追加
         `C:\Users\MyPC\Desktop\AI-Agents\company\shorts\assets\endcard.png` → 全画面・2〜3秒
   - [ ] **書き出し前に先頭のVREWロゴ区間を確認**（Vrew無料プランは冒頭一瞬にVREWロゴが入る。先頭クリップの頭を少し詰める/カットして、フックのナレーションは残しつつロゴを出さない）
   - [ ] 1080×1920 で書き出し → `Desktop\AIコンサル\ショート動画\`
   - [ ] Claudeにmp4のパスを投げてチェック
   - [ ] YouTube: **タイトルは台本の「タイトル案」を使う（ファイル名の先頭2桁番号は入れない）**。番号は管理用でファイル名だけに残す／**タイトルの末尾に `#shorts` を付ける**（スペースなしで直後。とーるさんの方針で過去分も全部付けている。見つけても消すよう案内しない）／概要欄コピペ（ハッシュタグは概要欄本文に）／子ども向け「いいえ」／**AIの使用「いいえ」**（ケアしば＝イラストは開示不要）
   - [ ] **タグ欄に「タグ欄用キーワード」をコピペ**（#なし・カンマ区切り。概要欄のハッシュタグとは別物）
   - [ ] 火 or 金 18:00 で予約 → 固定コメント投稿
   - [ ] サムネ（スマホアプリ限定）: ✏️ →「<おすすめフレームの秒数と内容>」を選ぶ
   - [ ] 公開URLをClaudeに貼る → published.md に記録
   ```

**発信ルール（厳守）**
- 誇大・断定NG。制度・医療・お金の数字は根拠が曖昧なら Web検索で確認してから書く
- 出典が必要な数字は概要欄に「出典: ○○」を入れる
- となりにAIブランド＝安心・誠実・置いていかない

### 公開サポート
1. `company/shorts/workflow.md` の公開チェックリストを表示
2. 対象の台本ファイルからタイトル・概要欄・ハッシュタグをコピペ用に整形して出す（タイトルは末尾に `#shorts` を付けた形で出す）
3. 公開報告を受けたら `company/shorts/published.md` に1行追記

### 分析
1. vidiqチャンネル連携済みなら channel_analytics / video_stats で直近の数字を取得
2. 未連携なら published.md の手入力の数字でレビュー
3. 「伸びたフックの型」「弱いシリーズ」を1〜2行で指摘し、次週のネタ選びに反映

## コミュニケーション
- フランクに。まず成果物（ネタ候補 or 台本）を見せてから保存報告
- vidiqのクレジット消費が発生する操作（動画生成など）は、実行前に消費量を伝えて確認する
