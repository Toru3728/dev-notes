# /my-stamp — LINEスタンプ制作・販売サポート

とーるさんのLINEスタンプ制作を、企画→画像→申請まで伴走するコマンド。
口調はフランクに。作業フォルダは `company/stamp/<セット名>/`。

## 仕様の前提（LINE Creators Market）
- スタンプ画像: 最大370×320px / PNG / 背景透過 / 余白10px程度 / 8・16・24・32・40個から選択
- メイン画像 240×240px、トークルームタブ画像 96×74px、各1MB以下、ZIPで申請
- AI生成画像はOKだが、販売申請時に「AIの使用」を申告必須（購入ページに表示が入る）
- 分配は売上の約35%。収益より「名刺代わり・ブランディング」と割り切るのが現実的

## 進め方

### STEP 1: 企画（ヒアリング）
以下を質問して決める（雑な答えでもこちらで整理する）:
1. キャラクター案（例: 介護現場の「うなずきおじさん」、ケアマネ猫 など）
2. ターゲット（介護職員同士のトーク？ 家族との連絡？ 一般向け？）
3. 個数（初回は**8個**を推奨。審査も制作も軽い）

### STEP 2: セリフ・ポーズ案の作成
個数分のセリフ＋ポーズ案を表で提案する。
介護現場向けなら「申し送りOK」「記録おわった！」「今日も無事故」「お疲れさまです」など、
現場のリアルな声（company/chousa/genba-faq.md も参考になる）を反映する。

### STEP 3: 画像づくり
とーるさんの選択肢を提示:
- **Canva**（AI画像生成＋背景透過ダウンロード。統一感を出しやすい）
- **ChatGPT/画像生成AI**（キャラ設定プロンプトを固定して量産。背景は白指定）
- 手描き・写真ベースでもOK
キャラの一貫性を保つ「共通プロンプト」を作って渡すこと。
できた画像は `company/stamp/<セット名>/src/` に保存してもらう。

### STEP 4: 整形＆ZIP化（自動）
```
python build_line_stamp.py company/stamp/<セット名> --main 1 --whitebg
```
- リサイズ・余白・main/tab生成・1MBチェック・ZIP化まで全自動
- `--whitebg` は白背景画像を透過にするオプション（すでに透過済みなら不要）
- `--main N` でメイン画像に使う番号を指定

### STEP 5: 申請サポート
以下の下書きを作って渡す:
- スタンプタイトル（英語も必要）／説明文（日本語・英語）／コピーライト表記
- 販売価格の推奨（初回は最低価格の120円台でOK）
- チェックリスト: AIの使用申告 / プライベート設定は「公開」/ テキストに宣伝・日付を入れない（リジェクト対象）
- **画像NG例（実際にリジェクトされたもの）**: 赤十字マークおよび類似マーク（赤系統の十字）は使用禁止（ガイドライン5.1）。医療モチーフは絆創膏・聴診器などで代用する

### STEP 6: 販売後
- 審査は通常数日〜1週間。結果が出たら /my-insta で告知投稿文を作る
- 売上や反応は company/secretary/logs/ の日報に記録
