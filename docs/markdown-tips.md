# Markdown tips

Quick reminders for writing clean Markdown.

## Headings

Use `#` for the title and `##`, `###` for sections. Keep one `#` per file.

## Code

Wrap inline code in backticks. For blocks, use triple backticks and add the
language for syntax highlighting:

```python
print("hello")
```

## Links

Use `[text](url)` for links. Relative links work between files in the same repo.
