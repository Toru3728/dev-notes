# 議事録作成の自動化

会議の録音から、配布できる Word の議事録まで。

**やることは2つだけ。会議を録音する。録音したものを Claude に投げる。**
あとは Claude がやる。整形も Word 化も、配布前のチェックも、レイアウトの目視まで。

---

## 使い方

### 1. 会議を録音する

対面ならスマホのボイスメモ、オンラインなら会議ツールの録画。それだけ。

**冒頭にこれを声に出して吹き込む。**

> 「2026年9月30日、○○事業所サービス担当者会議。出席は…」

これだけで議事録の会議名・日時・出席者が埋まる。あとで聞かれずに済む。

### 2. Claude に投げる

```
/my-gijiroku
```

そこに録音の文字起こし、または会議中のメモを貼る。雑な箇条書きで構わない。

**足りないものがあれば Claude が聞いてくる。** 会議名が分からない、ToDo の期限が読み取れない、
といったときだけ。まとめて1回で聞くので、答えたら終わり。分からないものは「任せる」でいい。

### 3. 出てきたものを受け取る

Word の議事録が `company/secretary/minutes/` に保存される。あわせてこう報告が来る。

```
議事録できたよ → company/secretary/minutes/2026-09-30_A様担当者会議.docx

配布前チェック: 通った
レイアウト: 見た（崩れなし）
```

**「配布前チェック: 通った」まで出ていれば、そのまま配れる。**
`［要確認］` の残りも、ToDo の担当・期限の空欄も、仮名化し忘れた氏名も、
Claude が機械的に確認したうえでの「通った」なので。

## 事業所の様式に合わせたいとき

事業所によって議事録の様式が違う（Word・Excel・紙の手書き）。
**初回だけ、その事業所の様式を写真で撮って投げる。** 2回目以降は何もしなくていい。

```
/my-gijiroku
（様式の写真を添付）
```

Claude が項目名と並びを読み取って覚える。次からはその事業所の体裁で出てくる。

### 写真の撮り方

- 項目名が全部見えるページを**真上から**撮る。斜めだと表の列が読めない
- **記入済みのものを撮るなら、利用者名が写っている部分を付箋で隠す**か、白紙の様式を撮る
- Excel の様式なら、印刷プレビューの画面キャプチャでもいい

### 覚えたあとの体裁

項目名・並び・表の列は**その事業所のまま**。そこに3つだけ足す。

| 足すもの | なぜ |
|---|---|
| ToDo の「担当」「期限」 | 誰がいつまでにが抜けた ToDo は、あとで必ず揉める |
| ［要確認］一覧 | 聞き取れなかった箇所の置き場。ここが空になって初めて配れる |
| 配布前チェック欄 | 個人情報の残りを最後に必ず見る。配布時に削除する |

様式に既に「担当」欄があれば重複しない。

## 介護・福祉の会議で気をつけること

利用者名・病名・家族の事情が出る会議なので、ここだけは人が決める。

| いつ | 何を |
|---|---|
| 録音する前 | 「記録のために録音します」と一言。オンラインは通知が出るが、それでも口で言う |
| 文字起こしするとき | 要配慮個人情報を含む会議は、クラウドの文字起こしサービスに上げない（下記） |
| 配布する前 | 利用者名が `A様` `B様` になっているか。Claude もチェックするが、最後は目で見る |
| 議事録が確定したら | 音声は削除する。残すなら保管期限を決める |

### 個人情報を含む会議の文字起こし

クラウドのサービス（Notta・Vrew など）は手軽だが、音声がネットに出る。
利用者情報を含む会議は、PC の中だけで動く Whisper を使う。

```bash
pip install faster-whisper
faster-whisper 2026-09-30_担当者会議.m4a --language ja --model medium --output_format txt
```

出てきたテキストを `/my-gijiroku` に貼る。誤変換だらけでいい。直すのは Claude の仕事。

## 録音のコツ（ここで精度の8割が決まる）

- マイクは話者から**1m以内**、テーブルの中央。エアコンの吹き出し口の下は避ける
- 机に直置きすると振動音を拾う。ハンカチ1枚敷く
- **発言の前に名前を言うルール**にすると話者の区別がつく。司会が「では田中さん」と振るだけでもいい
- ホワイトボードや配布資料は**写真を撮る**。音声に残らない情報は後から復元できない
- 会議が終わったらその場でファイル名を `YYYY-MM-DD_会議名.m4a` に変える。後回しにすると分からなくなる

## うまくいかないとき

| 症状 | どうするか |
|---|---|
| 文字起こしが崩壊している | マイクが遠い or 複数人が同時に話している。録音位置を見直す |
| 専門用語が全部誤変換 | そのまま投げてよい。Claude が直す |
| 決定事項が薄い | 会議で決め切っていない。議事録の問題ではないので、会議の最後に「では決まったことを確認します」を入れる |
| 出席者が拾えず毎回聞かれる | 冒頭の吹き込みを忘れている |
| `［要確認］` が残ると言われた | 聞き取れなかった箇所。音声のその辺りを聞き直して、答えを Claude に渡す |
| 「レイアウト未確認」と言われた | プレビュー画像が作れない環境だった。Word で開いて崩れがないか見る |

## 所要時間の目安（1時間の会議）

| やること | 時間 | 誰が |
|---|---|---|
| 録音 | 会議時間と同じ | とーる（追加作業ゼロ） |
| 文字起こし | 5〜15分 | 待つだけ |
| 投げる | 1分 | とーる |
| 整形・Word 化・チェック・目視 | 2〜3分 | Claude |
| 最終確認 | 3〜5分 | とーる |

手打ちで60〜90分かかっていた作業が、**実作業5分前後**になる。
